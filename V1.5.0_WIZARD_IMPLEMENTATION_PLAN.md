# V1.5.0 WIZARD IMPLEMENTATION PLAN

**Feature**: Wizard-Driven Setup & Onboarding
**Date**: August 21, 2026
**Status**: Implementation plan ready

---

## 1. EXECUTIVE SUMMARY

Add a setup wizard that guides new users through:
1. Welcome & plugin overview
2. Post type selection
3. Relationship type creation
4. Core settings configuration

**Goal**: Transform blank first-visit experience into guided onboarding.

```
    │
    └── NO → Normal admin flow
```

## 3. WIZARD STEPS

### Step 1: Welcome

**Purpose**: Introduce the plugin, set expectations.

**Content**:
- Plugin name + tagline
- 3 key benefits (native, fast, developer-friendly)
- "Get Started" button
- "Skip Setup" link (creates defaults)

**API calls**: None

**State**: Mark step 1 complete on proceed

---

### Step 2: Post Type Selection

**Purpose**: Choose which post types are enabled for relationships.

**Content**:
- Title: "Choose Post Types"
- Description: "Select which content types can have relationships."
- Checkbox grid: All registered post types (public + private)
- Default selected: `post`, `page`
- "Select All" / "Deselect All" toggles
- "Continue" button

**API calls**: None (reads from WP API)

**State**: Store selected types temporarily (not saved until Step 4)

**Logic**:
```php
$post_types = get_post_types(['public' => true], 'objects');
// Add private types if user has capability
if (current_user_can('edit_private_posts')) {
    $post_types = array_merge($post_types, get_post_types(['public' => false], 'objects'));
}
```

---

### Step 3: Relationship Types

**Purpose**: Create initial relationship types.

**Content**:
- Title: "Create Relationship Types"
- Description: "Define how your content connects."
- Type cards (from Presets):
  - Related (default)
  - Part Of (parent-child)
  - Referenced By (citation)
  - Custom (user-defined)
- Each card has: name, description, cardinality, bidirectional toggle
- "Add Custom Type" button
- "Continue" button

**API calls**: None (creates in Step 4)

**State**: Store type configurations temporarily

**Logic**:
```php
$presets = NATICORE_Presets::get_presets();
// Show top 4 presets + custom option
```

---

### Step 4: Settings Configuration

**Purpose**: Configure core settings.

**Content**:
- Title: "Configure Settings"
- Description: "Set up how relationships work."
- Settings cards:
  - Performance: Lazy Load, Optimized Query
  - Behavior: Direction, Manual Ordering, Bidirectional Sync
  - Safety: Circular Prevention, Cleanup on Delete
  - Automation: Auto-Link, AI Suggestions (disabled by default)
- "Finish Setup" button

**API calls**: Save via Settings API

**State**: Save all settings, mark wizard complete

**Logic**:
```php
// Use existing Settings API
update_option('naticore_settings', $settings);
update_option('naticore_wizard', [
    'completed' => true,
    'completed_at' => current_time('mysql'),
    'version' => '1.5.0',
]);
```

## 4. WIZARD STATE MANAGEMENT

### 4.1 Option Schema

```php
// naticore_wizard option
[
    'completed' => true,              // bool
    'completed_at' => '2026-08-21',   // string (ISO date)
    'version' => '1.5.0',            // string (for re-runs)
    'steps_completed' => [           // array
        'welcome' => true,
        'post_types' => true,
        'relationship_types' => true,
        'settings' => true,
    ],
]
```

### 4.2 State Flow

```
should_run() → true
    │
    ▼
render_step(1) → step=1
    │
    ▼ [Continue]
update_step(1, complete) → step=2
    │
    ▼ [Continue]
update_step(2, complete) → step=3
    │
    ▼ [Continue]
update_step(3, complete) → step=4
    │
    ▼ [Finish]
complete() → wizard.completed=true → redirect to Relationships
```

### 4.3 Skip Flow

```
should_run() → true
    │
    ▼ [Skip Setup]
create_defaults() → wizard.completed=true → redirect to Relationships
```

**create_defaults()**:
- Enable `post` and `page` post types
- Create "Related" type (unidirectional)
- Create "Part Of" type (unidirectional)
- Save default settings

## 7. WIZARD PHP CLASSES

### 7.1 NATICORE_Wizard (Controller)

```php
<?php
/**
 * Wizard controller — manages state and flow.
 */
class NATICORE_Wizard {
    
    const OPTION_KEY = 'naticore_wizard';
    const VERSION = '1.5.0';
    
    /**
     * Check if wizard should run.
     */
    public static function should_run() {
        // Only on first visit
        if (get_option(self::OPTION_KEY . '_dismissed')) {
            return false;
        }
        
        // Only for admins
        if (!current_user_can('manage_options')) {
            return false;
        }
        
        // Only on Naticore pages
        $page = isset($_GET['page']) ? sanitize_text_field($_GET['page']) : '';
        if (strpos($page, 'naticore') === false) {
            return false;
        }
        
        return true;
    }
    
    /**
     * Get current step.
     */
    public static function get_current_step() {
        $state = get_option(self::OPTION_KEY . '_state', []);
        return isset($state['current_step']) ? $state['current_step'] : 1;
    }
    
    /**
     * Update step.
     */
    public static function update_step($step, $data = []) {
        $state = get_option(self::OPTION_KEY . '_state', []);
        $state['current_step'] = $step;
        $state['steps_completed'][$step] = true;
        $state = array_merge($state, $data);
        update_option(self::OPTION_KEY . '_state', $state);
    }
    
    /**
     * Complete wizard.
     */
    public static function complete() {
        $state = get_option(self::OPTION_KEY . '_state', []);
        update_option(self::OPTION_KEY, [
            'completed' => true,
            'completed_at' => current_time('mysql'),
            'version' => self::VERSION,
            'steps_completed' => $state['steps_completed'] ?? [],
        ]);
        delete_option(self::OPTION_KEY . '_state');
    }
    
    /**
     * Create defaults (skip flow).
     */
    public static function create_defaults() {
        // Enable post types
        $settings = get_option('naticore_settings', []);
        $settings['enabled_post_types'] = ['post', 'page'];
        $settings['default_direction'] = 'unidirectional';
        $settings['prevent_circular'] = 1;
        $settings['cleanup_on_delete'] = 'remove';
        update_option('naticore_settings', $settings);
        
        // Create default types
        NATICORE_Relation_Types::add_type([
            'label' => 'Related',
            'slug' => 'related',
            'bidirectional' => false,
            'from' => ['post', 'page'],
            'to' => ['post', 'page'],
        ]);
        
        NATICORE_Relation_Types::add_type([
            'label' => 'Part Of',
            'slug' => 'part_of',
            'bidirectional' => false,
            'from' => ['post', 'page'],
            'to' => ['post', 'page'],
        ]);
        
        self::complete();
    }
}
```

### 7.3 NATICORE_Wizard_API (AJAX)

```php
<?php
/**
 * Wizard AJAX endpoints.
 */
class NATICORE_Wizard_API {
    
    /**
     * Register AJAX hooks.
     */
    public static function init() {
        add_action('wp_ajax_naticore_wizard_save_step', [__CLASS__, 'ajax_save_step']);
        add_action('wp_ajax_naticore_wizard_complete', [__CLASS__, 'ajax_complete']);
        add_action('wp_ajax_naticore_wizard_skip', [__CLASS__, 'ajax_skip']);
    }
    
    /**
     * Save wizard step.
     */
    public static function ajax_save_step() {
        check_ajax_referer('nc_stitch_nonce', 'nonce');
        
        if (!current_user_can('manage_options')) {
            wp_send_json_error('Unauthorized');
        }
        
        $step = intval($_POST['step'] ?? 0);
        $data = $_POST['data'] ?? [];
        
        NATICORE_Wizard::update_step($step, $data);
        
        wp_send_json_success(['step' => $step]);
    }
    
    /**
     * Complete wizard.
     */
    public static function ajax_complete() {
        check_ajax_referer('nc_stitch_nonce', 'nonce');
        
        if (!current_user_can('manage_options')) {
            wp_send_json_error('Unauthorized');
        }
        
        $settings = $_POST['settings'] ?? [];
        $types = $_POST['types'] ?? [];
        
        // Save settings
        if (!empty($settings)) {
            $current = get_option('naticore_settings', []);
            update_option('naticore_settings', array_merge($current, $settings));
        }
        
        // Create types
        foreach ($types as $type) {
            NATICORE_Relation_Types::add_type($type);
        }
        
        NATICORE_Wizard::complete();
        
        wp_send_json_success([
            'redirect' => admin_url('admin.php?page=naticore-relationships'),
        ]);
    }
    
    /**
     * Skip wizard (create defaults).
     */
    public static function ajax_skip() {
        check_ajax_referer('nc_stitch_nonce', 'nonce');
        
        if (!current_user_can('manage_options')) {
            wp_send_json_error('Unauthorized');
        }
        
        NATICORE_Wizard::create_defaults();
        
        wp_send_json_success([
            'redirect' => admin_url('admin.php?page=naticore-relationships'),
        ]);
    }
}
```

```php
/**
 * Register wizard page.
 */
public function register_wizard_page() {
    add_submenu_page(
        'naticore-hidden',
        'Setup Wizard',
        'Setup Wizard',
        'manage_options',
        'naticore-wizard',
        [$this, 'render_wizard']
    );
}

/**
 * Render wizard page.
 */
public function render_wizard() {
    if (!NATICORE_Wizard::should_run()) {
        wp_redirect(admin_url('admin.php?page=naticore-relationships'));
        exit;
    }
    
    $step = NATICORE_Wizard::get_current_step();
    
    NATICORE_Wizard_Renderer::render_wrapper_start();
    
    switch ($step) {
        case 1:
            NATICORE_Wizard_Renderer::render_step_welcome();
            break;
        case 2:
            NATICORE_Wizard_Renderer::render_step_post_types();
            break;
        case 3:
            NATICORE_Wizard_Renderer::render_step_types();
            break;
        case 4:
            NATICORE_Wizard_Renderer::render_step_settings();
            break;
    }
    
    NATICORE_Wizard_Renderer::render_wrapper_end($step, 4);
}
```
